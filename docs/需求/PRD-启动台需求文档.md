# AppLaunchpad - macOS 启动台需求文档

**版本**: v1.0.0  
**日期**: 2026-07-20  
**状态**: 草稿

---

## 一、项目背景

macOS 26 系统升级后，系统原生 Launchpad（启动台）功能被移除。用户需要一个能够完整替代原生启动台的第三方应用，保持与原生 Launchpad 一致的交互体验，同时支持 macOS 26 的设计规范。

---

## 二、目标与范围

### 2.1 产品目标

- 完整还原 macOS 原生 Launchpad 的核心功能与视觉体验
- 支持 macOS 26 Liquid Glass 设计语言
- 以全屏模式展示所有已安装应用，提供快速启动入口
- 支持文件夹分组、应用搜索、图标排列等功能

### 2.2 目标用户

- 从 macOS 25 及以下升级至 macOS 26 的用户
- 习惯使用 Launchpad 管理/启动应用的 Mac 用户

### 2.3 项目范围（In Scope）

| 功能模块 | 说明 |
|---------|------|
| 全屏应用展示 | 全屏覆盖，背景虚化，展示所有应用图标 |
| 应用图标网格 | 多行多列自适应布局，图标支持动态效果 |
| 多页翻页 | 应用超出一页时支持左右翻页 |
| 搜索功能 | 顶部搜索框，实时过滤应用 |
| 文件夹功能 | 拖拽创建文件夹、文件夹展开/收起 |
| 图标抖动编辑模式 | 长按进入编辑模式，图标抖动，可删除/移动 |
| 应用启动 | 点击图标启动对应应用 |
| 快捷键触发 | 支持快捷键、触控板手势呼出 |
| Dock 图标 | 在 Dock 中提供启动台图标 |

### 2.4 排除范围（Out of Scope）

- App Store 下载功能（仅打开 App Store 应用）
- 应用卸载功能（仅 Mac App Store 应用支持删除标记，实际卸载跳转系统）

## 三、功能需求

### 3.1 应用入口与呼出方式

#### 3.1.1 触发方式

| 触发方式 | 描述 | 优先级 |
|---------|------|--------|
| Dock 点击 | 点击 Dock 中的启动台图标 | P0 |
| 键盘快捷键 | 默认 `F4`，支持用户自定义 | P0 |
| 触控板手势 | 四指/五指捏合手势呼出 | P1 |
| 菜单栏图标 | 菜单栏提供快捷入口（可选） | P2 |

#### 3.1.2 呼出动画

- 应用图标从原始位置（Dock/桌面）飞入，放大展开至全屏
- 背景逐渐模糊（壁纸虚化效果）
- 动画时长约 350ms，使用弹性缓动曲线

#### 3.1.3 关闭方式

| 关闭方式 | 描述 |
|---------|------|
| `Escape` 键 | 关闭启动台 |
| 点击背景空白区域 | 关闭启动台 |
| 启动应用 | 点击图标后自动关闭 |
| 触控板捏合展开手势 | 反向手势关闭 |

### 3.3 应用数据获取

#### 3.3.1 应用扫描范围

按优先级顺序扫描以下路径：

1. `/Applications/` — 系统级应用（包含子目录）
2. `~/Applications/` — 用户级应用
3. `/System/Applications/` — macOS 系统自带应用
4. `/Applications/Utilities/` — 实用工具

#### 3.3.2 应用过滤规则

**包含**：
- 扩展名为 `.app` 的 Bundle
- `Info.plist` 中 `LSUIElement` 为 `false` 或不存在
- `CFBundleIconFile` 有效的应用

**排除**：
- `Info.plist` 中 `LSBackgroundOnly = true`
- `NSUIElement = true`（纯后台应用）
- 以 `.` 开头的隐藏目录下的应用
- 已知系统内部工具（如 `Installer.app` 内嵌组件）

#### 3.3.3 应用信息获取

| 字段 | 来源 |
|-----|------|
| 应用名称 | `CFBundleDisplayName` > `CFBundleName` > 文件名 |
| 应用图标 | `NSWorkspace.icon(forFile:)` |
| Bundle ID | `CFBundleIdentifier` |
| 应用路径 | 文件系统路径 |
| 应用版本 | `CFBundleShortVersionString` |
| 是否 MAS 应用 | 判断 `_MASReceipt` 目录 |

#### 3.3.4 应用列表动态刷新

- 监听 `/Applications/`、`~/Applications/` 目录变化（`FSEvents`）
- 应用安装/卸载后自动刷新图标列表
- 刷新时保留用户自定义排列顺序

### 3.4 多页翻页功能

#### 3.4.1 翻页交互

| 交互方式 | 行为 |
|---------|------|
| 触控板双指左右滑动 | 切换页面 |
| 键盘左/右方向键 | 切换页面 |
| 点击页面指示器圆点 | 跳转到对应页 |
| 鼠标拖拽 | 超过 50pt 后切换页面 |

#### 3.4.2 翻页动画

- 当前页整体左移/右移，下一页从右/左滑入
- 动画时长：300ms
- 缓动函数：`easeInOut`
- 翻页过程中显示中间过渡状态（可见两页的部分内容）

#### 3.4.3 页面指示器

- 位置：底部居中，距底边约 30pt
- 当前页：实心白色圆点（直径8pt）
- 其他页：半透明白色圆点（直径6pt，透明度50%）
- 页数超过1页时才显示

---

### 3.5 搜索功能

#### 3.5.1 搜索框

- 位置：顶部居中，距顶边约 60pt
- 宽度：约 400pt
- 高度：约 36pt
- 样式：圆角矩形，半透明 Liquid Glass 材质
- 前缀图标：放大镜图标
- 占位文字：「搜索」
- 呼出启动台时自动聚焦（可选，用户设置控制）

#### 3.5.2 搜索行为

- 实时搜索（无需按回车）
- 搜索范围：应用名称（中文/英文均支持）、Bundle ID
- 搜索算法：前缀匹配 + 模糊匹配，相关度排序
- 搜索时隐藏文件夹，直接展示应用图标
- 搜索结果无应用时显示「无结果」提示

#### 3.5.3 搜索状态

| 状态 | 显示方式 |
|-----|---------|
| 无搜索词 | 正常显示所有应用，多页布局 |
| 有搜索词 | 单页展示匹配结果，不显示页码指示器 |
| 无匹配结果 | 居中显示「未找到应用」提示文字 |

---

### 3.6 文件夹功能

#### 3.6.1 创建文件夹

- 进入编辑模式后，拖拽一个图标到另一个图标上方 → 自动创建文件夹
- 文件夹默认名称：由系统根据应用类别自动推断（如「工具」「游戏」「效率」）
- 支持用户点击文件夹名称进行重命名

#### 3.6.2 文件夹展示

| 状态 | 视觉表现 |
|-----|---------|
| 收起 | 显示为圆角矩形，内部展示最多9个小图标（3×3） |
| 展开 | 放大，背景遮罩，内部滚动展示所有应用图标 |

#### 3.6.3 文件夹展开

- 点击文件夹图标 → 展开动画（从文件夹位置放大展开）
- 展开后背景半透明模糊
- 文件夹内图标布局：每行4个，多行滚动
- 点击文件夹外部区域 → 收起动画

#### 3.6.4 文件夹内部操作（编辑模式）

- 在文件夹内拖拽图标到外部 → 移出文件夹
- 当文件夹只剩1个应用时，自动解散文件夹

#### 3.6.5 文件夹命名

- 点击文件夹标题进入编辑状态
- 显示文本输入框，支持任意名称
- 按 `Return` 或点击外部区域确认
- 名称为空时恢复系统默认名称

---

### 3.7 编辑模式（图标抖动）

#### 3.7.1 进入/退出编辑模式

| 触发方式 | 行为 |
|---------|------|
| 长按任意图标（0.6秒） | 进入编辑模式 |
| 按 `Escape` 键 | 退出编辑模式（不关闭启动台） |
| 点击空白区域 | 退出编辑模式 |

#### 3.7.2 编辑模式视觉效果

- 所有图标开始轻微抖动（左右摇摆，随机相位）
- MAS 应用图标左上角显示「×」删除按钮
- 非 MAS 应用不显示「×」按钮（无法通过启动台卸载）

#### 3.7.3 图标拖拽排序

- 进入编辑模式后支持拖拽图标调整顺序
- 拖拽时：被拖拽图标放大（scale 1.15）并提升到最上层
- 经过其他图标位置时，其他图标自动让位（动画过渡）
- 松开后：图标落回最近的空位，触发弹性动画
- 支持跨页拖拽：拖至屏幕边缘 → 自动翻页

#### 3.7.4 删除应用（MAS 应用）

- 点击「×」按钮 → 弹出确认对话框
- 确认后：执行系统卸载流程（调用 `LaunchServices` 或打开 `Finder` 定位）
- 图标从列表中移除，其余图标补位

---

### 3.8 应用启动

- 单击图标 → 启动台关闭动画 → 调用 `NSWorkspace.open(URL)` 启动应用
- 若应用已运行 → 直接切换至该应用（置前）
- 若应用正在安装（进度条状态）→ 显示进度，禁用点击启动

---

### 3.9 Dock 集成

- 应用在 Dock 中显示为固定图标（系统风格启动台图标）
- 点击 Dock 图标：
  - 若启动台未显示 → 呼出启动台
  - 若启动台已显示 → 关闭启动台

## 四、非功能需求

### 4.1 性能要求

| 指标 | 要求 |
|-----|------|
| 冷启动时间（首次呼出） | ≤ 500ms |
| 热启动时间（再次呼出） | ≤ 100ms |
| 应用列表扫描完成时间 | ≤ 1000ms（首次），后台刷新不阻塞UI |
| 翻页/搜索响应延迟 | ≤ 16ms（60fps） |
| 内存占用（常驻后台） | ≤ 30MB |
| 内存占用（展示中） | ≤ 100MB |

### 4.2 兼容性

| 要求 | 说明 |
|-----|------|
| 最低系统版本 | macOS 26.0 |
| 目标系统版本 | macOS 26.x |
| 架构支持 | Apple Silicon (arm64) + Intel (x86_64) Universal Binary |
| 分辨率适配 | 支持 Retina 显示屏（@2x），支持外接显示器 |
| 多显示器 | 启动台在主显示器展示，或在鼠标所在显示器展示（可配置） |
| 深色/浅色模式 | 自动跟随系统 |

### 4.3 可靠性

- 图标加载失败时显示默认应用图标，不影响其他应用展示
- 应用路径无效（已卸载）时，下次刷新后自动从列表移除
- 排列配置（顺序/文件夹）持久化存储，重启后保留

### 4.4 安全与权限

| 权限 | 用途 | 必需 |
|-----|------|------|
| 文件系统读取（`/Applications`） | 扫描应用 | 是 |
| Accessibility（可选） | 触控板手势支持 | 否（降级处理） |
| 无沙盒限制（Hardened Runtime） | 访问系统路径、监听 FSEvents | 是 |

## 六、UI 设计规范

### 6.1 视觉风格

- 遵循 **macOS 26 Liquid Glass** 设计语言
- 背景：壁纸高斯模糊 + 半透明遮罩
- 图标：标准 macOS 圆角图标，支持阴影
- 文字：SF Pro Display/Text，白色，带文字阴影提升可读性
- 搜索框/文件夹：Liquid Glass 材质，浅色/深色自适应

### 6.2 动画规范

| 动画 | 时长 | 缓动 |
|-----|------|------|
| 呼出/关闭 | 350ms | `spring(dampingFraction: 0.75)` |
| 翻页 | 300ms | `.easeInOut` |
| 图标抖动 | 循环，周期 0.1s | 正弦曲线 |
| 文件夹展开 | 250ms | `spring(dampingFraction: 0.8)` |
| 图标拖拽让位 | 200ms | `.easeInOut` |
| 图标落位 | 300ms | `spring(dampingFraction: 0.7)` |
| 搜索结果刷新 | 150ms | `.easeOut` |

### 6.3 交互反馈

- Hover 悬停：图标轻微放大（scale 1.05），无额外效果
- 点击按下：图标缩小（scale 0.9），释放后启动
- 搜索无结果：轻微震动反馈 + 提示文字

## 八、技术实现建议

### 8.1 技术栈

| 组件 | 方案 |
|-----|------|
| UI 框架 | SwiftUI（主体） + AppKit（Dock 集成、系统交互） |
| 应用扫描 | `NSWorkspace` + `FileManager` + `FSEvents` |
| 全屏窗口 | `NSPanel`（`.nonactivating` 级别） |
| 图标获取 | `NSWorkspace.shared.icon(forFile:)` |
| 持久化 | `UserDefaults` / `Codable` JSON |
| 手势识别 | `NSPressGestureRecognizer`（长按）+ `NSPanGestureRecognizer`（拖拽）|
| 触控板手势 | `NSEvent.addGlobalMonitorForEvents` + `MagnificationGesture` |

### 8.2 关键技术点

1. **全屏窗口层级**：使用 `NSPanel` + `level = .screenSaver` 确保覆盖在所有窗口之上
2. **背景虚化**：截取当前屏幕画面，使用 `CIFilter.gaussianBlur()` 处理
3. **FSEvents 监听**：监听 `/Applications` 路径变化，防抖动（debounce 2s）后刷新应用列表
4. **图标缓存**：使用 `NSCache<NSString, NSImage>` 管理图标缓存，避免内存泄漏
5. **Dock 图标**：使用 `LSUIElement = true` 隐藏主窗口，通过 `NSApp.setActivationPolicy` 动态切换
