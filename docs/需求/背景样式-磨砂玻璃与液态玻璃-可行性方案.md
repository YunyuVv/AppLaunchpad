## 一、问题与目标

用户希望启动台提供**两种可切换的背景样式**：

1. **磨砂玻璃（当前样式）** —— 现状；
2. **macOS 26 液态玻璃（Liquid Glass）** —— 苹果在 macOS Tahoe 26 引入的新材质。

并且文件夹展开面板的背景也一并支持两种样式。目标：做一个**设置项**，用户可随时切换，实时生效。

---

## 二、现状确认：当前是不是磨砂玻璃？

**是。当前背景就是标准磨砂玻璃（实时模糊窗口后方内容）。**

| 位置 | 当前实现 | 是否磨砂玻璃 |
|---|---|---|
| **启动台全屏背景** | `BackgroundView` → `ScreenBlurView`：`NSVisualEffectView`，`material = .fullScreenUI`，`blendingMode = .behindWindow`，`state = .active`；上层再叠 `Color.black.opacity(prefs.backgroundOverlayOpacity)`（默认 0.10） | ✅ 是（AppKit 标准 Vibrancy 材质，模糊实时屏幕画面） |
| **文件夹展开面板** | `FolderExpandedView.swift:107`：`.background(.ultraThinMaterial, in: RoundedRectangle(cornerRadius: 16))` + 白色描边 | ✅ 是（SwiftUI 系统材质，等同磨砂玻璃） |
| **搜索框** | `SearchBarView` 用材质背景（次要，跟随整体风格） | ✅ 是 |

> 当前背景的「磨砂」来自 `NSVisualEffectView` 的 `.fullScreenUI` 材质 + `blendingMode = .behindWindow`，它把桌面/其他窗口实时模糊后透出，再被一层半透明黑遮罩压暗以提升图标可读性。

## 三、macOS 26 液态玻璃（Liquid Glass）API 调研

### 3.1 公开 API（`NSGlassEffectView`）

苹果在 WWDC25 Session 310 中**正式给出** AppKit 接入液态玻璃的公开 API：

- **`NSGlassEffectView`**（macOS 26 / Xcode 26 引入）——把内容放在玻璃材质上。
- 关键属性：
  - `cornerRadius: CGFloat` —— 玻璃圆角；
  - `tintColor: NSColor?` —— 玻璃色调（默认跟随环境/强调色；可自定义）；
  - `style` —— `.regular`（常规折射玻璃）/ `.clear`（透明无模糊的清玻璃）等；
  - `contentView` —— 要置于玻璃之上的内容视图（几何由 Auto Layout 绑定到 contentView，无需手动同步）。
- **`NSGlassEffectContainerView`**（可选）—— 当多个玻璃形状彼此靠近时，用容器把它们组合，获得流畅一致的折射/采样效果。
- 行为特征：玻璃会**折射、反射周围内容**，并随内容/上下文动态变化（实时渲染 + 镜面高光）。

### 3.2 重要约束（来自苹果官方指引）

1. **玻璃是「顶层浮动」材质**：官方建议**只用于界面层级中最重要、处于顶层的浮动控件**（如工具栏、浮动按钮、导航），**不要**把它当成大块背景兄弟层。整屏铺满液态玻璃在视觉与性能上都偏重，需克制（弱 tint、大/无圆角）。
2. **不要作为兄弟背景层**：应把内容放进 `contentView`，而不是在内容后面放一个玻璃兄弟视图（否则玻璃的视觉处理不会应用到你的内容上）。
3. **SwiftUI 原生材质≠液态玻璃**：`.ultraThinMaterial` 等系统材质在 macOS 26 上仍是「模糊材质」，**不会**自动变成折射式液态玻璃。要真正获得液态玻璃观感，必须用 `NSGlassEffectView`（AppKit）。
4. **系统要求**：`NSGlassEffectView` 仅 macOS 26+ 可用，且需 Xcode 26 SDK 编译。

### 3.3 本项目的关键利好

`project.yml` 当前：

```yaml
deploymentTarget:
  macOS: "26.0"
# 以及
MACOSX_DEPLOYMENT_TARGET: "26.0"
```

**部署目标已经是 macOS 26.0**，因此：

- `NSGlassEffectView` 可直接使用，**无需 `@available(macOS 26, *)` 守卫**，也**无需为旧系统写回退**（App 本身不会在 <26 运行）。
- 但编译需要 **Xcode 26**；当前 `swift-plugin-server` 工具链损坏需先修复才能构建验证。

## 四、可行性结论

**✅ 完全可行。** 两项样式都基于 AppKit 材质，切换只是换 `NSView` 类型 / 材质，且项目已锁定 macOS 26，API 与部署目标完全匹配。

风险点（均可控，见第六节）：
- 整屏液态玻璃的**性能与视觉重量**（需实测帧率、克制 tint）；
- 液态玻璃模式下**黑遮罩叠加会发灰**（需在该模式下降低/忽略遮罩透明度）；
- 文件夹面板要真正用玻璃需把内容**包进 `NSGlassEffectView.contentView`**（比单纯换材质多一步宿主）。

## 五、落地方案（具体改动点）

### 5.1 新增偏好：`backgroundStyle`

在 `UserPreferences.swift` 的「外观」区新增（沿用现有 `@Observable` + `didSet` 写 UserDefaults 的约定）：

```swift
/// 背景样式：0 = 磨砂玻璃（当前），1 = macOS 26 液态玻璃
var backgroundStyle: Int = 0 {
    didSet {
        let v = (backgroundStyle == 1) ? 1 : 0
        if v != backgroundStyle { backgroundStyle = v }
        defaults.set(backgroundStyle, forKey: Keys.backgroundStyle)
    }
}
```

并在 `Keys` 枚举加 `static let backgroundStyle = "backgroundStyle"`；`resetAppearanceToDefault()` 里重置为 `0`；`init` 里从 `defaults` 读取。

### 5.2 启动台全屏背景：`BackgroundView` / `ScreenBlurView`

新增一个 `GlassBlurView: NSViewRepresentable` 返回 `NSGlassEffectView`（全屏），`BackgroundView` 按 `prefs.backgroundStyle` 二选一：

```swift
var body: some View {
    ZStack {
        if prefs.backgroundStyle == 1 {
            GlassBlurView().ignoresSafeArea()      // 液态玻璃
        } else {
            ScreenBlurView().ignoresSafeArea()      // 磨砂玻璃（现有）
        }
        // 遮罩：液态玻璃本身已半透折射，建议仅磨砂模式压暗，玻璃模式降到很低或 0
        if prefs.backgroundStyle == 0 {
            Color.black.opacity(prefs.backgroundOverlayOpacity).ignoresSafeArea()
        }
    }
}
```

`GlassBlurView` 草图：

```swift
private struct GlassBlurView: NSViewRepresentable {
    func makeNSView(context: Context) -> NSGlassEffectView {
        let glass = NSGlassEffectView()
        glass.cornerRadius = 0          // 全屏无圆角
        glass.tintColor = nil           // 跟随系统环境
        glass.state = .active
        return glass
    }
    func updateNSView(_ nsView: NSGlassEffectView, context: Context) {}
}
```

> 验证点：全屏 `NSGlassEffectView` 需正确折射面板背后桌面（面板是 borderless + `backgroundColor = .clear`，玻璃应能采样窗口后方内容）。若只看到黑/不折射，需确认面板透明性与玻璃层级。

### 5.3 文件夹面板背景：`FolderExpandedView`

`FolderExpandedView.swift:107` 当前是 `.background(.ultraThinMaterial, …)`。在玻璃模式下改为**把内容包进 `NSGlassEffectView`**（满足「内容放 contentView」的官方要求）：

新增可复用包装（放在共享位置，如 `Views/GlassHostingView.swift`）：

```swift
struct GlassHostingView<Content: View>: NSViewRepresentable {
    var cornerRadius: CGFloat = 16
    var tint: NSColor? = nil
    @ViewBuilder let content: () -> Content

    func makeNSView(context: Context) -> NSGlassEffectView {
        let glass = NSGlassEffectView()
        glass.cornerRadius = cornerRadius
        glass.tintColor = tint
        let hosting = NSHostingView(rootView: content())
        glass.contentView = hosting
        return glass
    }
    func updateNSView(_ nsView: NSGlassEffectView, context: Context) {
        if let hosting = nsView.contentView as? NSHostingView<Content> {
            hosting.rootView = content()
        }
    }
}
```

调用处（仅为示意，不动现有几何/手势）：

```swift
if prefs.backgroundStyle == 1 {
    GlassHostingView(cornerRadius: 16) {
        folderContentVStack   // 原 VStack(Text + appGrid)
    }
    .frame(width: panelW, height: panelH)
    .position(x: geo.size.width / 2, y: topInset + panelH / 2)
} else {
    folderContentVStack
        .frame(width: panelW, height: panelH)
        .background(.ultraThinMaterial, in: RoundedRectangle(cornerRadius: 16))
        .overlay(RoundedRectangle(cornerRadius: 16).stroke(.white.opacity(0.12), lineWidth: 0.5))
        .position(x: geo.size.width / 2, y: topInset + panelH / 2)
}
```

> 注意：玻璃只改变渲染层，`panelFrameBox` / `GeometryReader` / 拖拽手势等几何逻辑**不受影响**（内容视图结构不变，仅外层渲染容器不同）。

### 5.4 设置面板：`AppearancePane`

在「背景遮罩」Section 下方加「背景样式」Section：

```swift
Section("背景样式") {
    Picker("样式", selection: $prefs.backgroundStyle) {
        Text("磨砂玻璃").tag(0)
        Text("液态玻璃").tag(1)
    }
    .pickerStyle(.segmented)
    Text("液态玻璃需 macOS 26 及以上，并会折射桌面背景")
        .font(.caption).foregroundStyle(.secondary)
}
```

> 由于 `UserPreferences` 是 `@Observable`，改设置即实时重绘启动台与文件夹面板，**无需重启启动台**。

### 5.5 复用既有模式（参考 `references/LaunchNext`）

`references/LaunchNext` 已有 `BackgroundStyle` 枚举（`.blur` / `.glass`）+ 设置卡片 `backgroundStyleCard`（含「高斯模糊 / 液态玻璃」选项）。其枚举与设置 UI模式可直接借鉴；**但 LaunchNext 用的是 `NSVisualEffectView` 材质而非真 `NSGlassEffectView`**（它部署目标更老）。本项目应沿用其「样式枚举 + 设置项」思路，但玻璃实现替换为 `NSGlassEffectView`。

## 六、风险与注意

| 风险 | 说明 | 应对 |
|---|---|---|
| 视觉重量 | 整屏液态玻璃偏重，违背「玻璃只用于顶层浮动控件」的官方建议 | 全屏玻璃用 `cornerRadius = 0`、`tintColor = nil`、不加/低遮罩；folder 面板保留圆角玻璃 |
| 性能 | 实时折射 + 现有实时模糊双重开销 | 实测帧率；必要时玻璃模式降低模糊层级或限定 panels 用玻璃、全屏背景仍用磨砂 |
| 遮罩发灰 | 黑遮罩叠在玻璃上会变灰、失去折射感 | 玻璃模式下不叠/极低遮罩（见 5.2） |
| 折射失败 | 全屏 `NSGlassEffectView` 可能不采样窗口后方桌面 | 验证面板透明性与玻璃层级；必要时把玻璃设为窗口 contentView |
| 系统/编译 | 需 macOS 26 + Xcode 26 才能编译运行 | 部署目标已是 26.0，OK；先修 `swift-plugin-server` 工具链再做构建验证 |
| 文件夹几何 | 包玻璃后拖拽/落点几何是否仍准 | 玻璃只换渲染容器，内容视图不变 → 几何逻辑不受影响（5.3 已说明） |
| tint 自定义 | 是否暴露「玻璃色调」设置 | 本期默认 `nil`（跟随系统）；如需可在 `UserPreferences` 加 `glassTint` 可选设置（P2） |
