## 1. 键盘方向键 / 翻页行为（待决策 + 待实现）

### 背景
用户反馈并讨论了「键盘上下左右在启动台里的作用」，以及 AppLaunchpad 当前实现与原生启动台的差异。
核心问题：**左右方向键该不该用来翻页？**（原生并不翻页）

### 原生 macOS 启动台行为（调研结论）
- **上下左右**：在当前页的图标网格内移动「选中高亮」（像光标逐格移动），**不翻页**。
- **翻页仅两种方式**：① 触控板双指左右横扫；② 点底部分页小圆点（分页指示器）。
- **直接打字** → 自动触发搜索（搜索框无需先点，输入即激活）。
- **Return / Enter** → 打开当前高亮的 app。
- **Esc** → 先清空搜索词，再按一次关闭启动台。
- 高亮移到当前页边缘时**不会跨页**（右移到最后一列再按右会停住）。

### 当前 AppLaunchpad 实现（现状，**暂不改动**）
文件：`AppLaunchpad/Window/LaunchpadWindowController.swift` → `setupKeyMonitor`

| 按键 | 当前行为 |
|---|---|
| ← / →（无选中、非搜索） | **翻页** `goToPreviousPage / goToNextPage` |
| ↑ / ↓（无选中） | 移动网格选中 `moveGridSelection` |
| ← / → / ↑ / ↓（有选中） | 均移动网格选中 `moveGridSelection` |

与原生不一致：**原生四方向都只做页内移动、翻页仅触控板/圆点**；当前实现把左右改成了翻页、上下改成了选择。

### 待决策（设计取向，需用户拍板）
- **选项 A｜保持现状**：左右翻页 + 上下选择。纯键盘用户翻页方便，但偏离原生手感。
- **选项 B｜对齐原生**：四方向都做页内高亮移动，翻页只留触控板/点圆点（键盘不再触发翻页）。手感最像系统。
- **选项 C｜现状 + 设置项**：默认保持现状（左右翻页），在设置面板加「键盘翻页模式」开关，用户可切到原生模式（B）。

### 代办清单
- [ ] 与用户确认方向键设计取向（A / B / C）
- [ ] 若选 B：改 `setupKeyMonitor` —— 四方向在无选中时都做页内高亮移动；翻页不再由键盘触发（保留触控板 / 点圆点）
- [ ] 若选 C：在设置面板加「键盘翻页模式」开关，默认值 = 现状（左右翻页）
- [ ] 决策后同步更新本文件 + 代码注释
