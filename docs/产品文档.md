## 1. 产品定位

AppLaunchpad 是 **macOS 启动台（Launchpad）的替代应用**：全屏网格展示本机应用、支持搜索、拖拽重排、文件夹分组、外观主题切换，并通过菜单栏图标 + 全局快捷键后台常驻唤起。

- 部署目标：macOS 26.0
- Swift 6（严格并发 `SWIFT_STRICT_CONCURRENCY: complete`）
- 激活策略：`.regular`（有 Dock 图标）；窗口关闭不退出，后台常驻

### 2.9 设置窗口
标准 SwiftUI `Window(id:"settings")` 场景，系统标题栏/工具栏，普通独立窗口（**不**浮于启动台之上——"设置悬浮"已决策不做，见 `待办事项.md`）。

| Section | 内容 | 关键位置 |
|---|---|---|
| 通用（置顶默认） | 登录时自动启动开关、显示器选择 | `GeneralPane` |
| 外观 | 背景样式 Picker、密度、间距、透明度、外观三卡片 | `AppearancePane` |
| 交互 | 触控板翻页灵敏度、全局快捷键录制（HotkeyRecorder）、辅助功能权限 | `InteractionPane` |
| 关于 | 图标、版本号、联系方式（mailto）、登录项开关 | `AboutPane` |

- Toggle 统一 `.toggleStyle(.switch).controlSize(.regular)`（macOS 26 原生液态玻璃样式）
- 快捷键录制：`InteractionPane.HotkeyRecorder`（local keyDown monitor 捕获）

### 2.10 布局持久化
- `LayoutStore`（actor）读写 `~/Library/Application Support/AppLaunchpad/layout.json`
- 结构：`pages: [[LayoutItem]]`（`LayoutItem` 枚举 `.app`/`.folder`）+ `folders: [UUID: FolderInfo]` + `version`
- 保存时机：`LaunchpadData.saveLayout()`（原子写 + 清理空页）
- 偏好：`UserPreferences` → `UserDefaults`（按 bundle id `com.biliww.applaunchpad` 分域）

## 3. 已知设计约束（非缺陷）

1. **启动台面板层级极高**（`screenSaverWindow - 1`）：这是全屏覆盖启动台所必需的固有意，会盖住 Dock/菜单栏/普通窗口。设置窗口是普通独立窗口，启动台可见时打开设置会落在面板之后（用户已接受"不做悬浮"）。
2. **仅支持鼠标拖拽排序**：当前未实现触摸板拖拽排序（仅触控板**翻页**）。
3. **编辑态图标抖动未接入**：`WobbleModifier` 已定义但全代码库未调用（图标抖动动画当前不生效）。
4. **删除入口双轨**：既有右键菜单"删除"，编辑模式也有删除 X（见 `待办事项.md` 待澄清项）。
