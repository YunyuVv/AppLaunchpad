## 2. 构建 / 签名 / TCC

### 编译命令（本环境已验证 BUILD SUCCEEDED）
```bash
defaults write com.apple.dt.Xcode DisableBuildSystemSandbox -bool YES
xcodebuild -project AppLaunchpad.xcodeproj -scheme AppLaunchpad -configuration Debug clean build OTHER_SWIFT_FLAGS=-disable-sandbox 2>&1 | tail -40
defaults delete com.apple.dt.Xcode DisableBuildSystemSandbox 2>/dev/null || true
```
- **原因**：agent 容器禁止 `sandbox_apply`（任何进程 `sandbox-exec` 报 `Operation not permitted`），导致 `swiftc` 启动宏插件宿主 `swift-plugin-server` 沙箱失败 → `@Observable` 宏 `malformed response`。
- 两层关沙箱：① `DisableBuildSystemSandbox` 关 xcodebuild 自身 wrapper；② `OTHER_SWIFT_FLAGS=-disable-sandbox`（= swiftc `-disable-sandbox`）关宏插件宿主沙箱。`SWIFT_USE_SANDBOX=NO` 是**错误开关，无效**。
- DerivedData：`AppLaunchpad-dciqgsnljuefbxcijebpmzdlzaxq`；产物 `Build/Products/Debug/AppLaunchpad.app`。

### 签名
- `project.yml`：`CODE_SIGN_STYLE: Manual`、`CODE_SIGN_IDENTITY: "Apple Development"`、`DEVELOPMENT_TEAM: 2VU69Q9CGK`、`ENABLE_HARDENED_RUNTIME: YES`。
- 手动签名让 TCC 权限按 Team 绑定、重编译不失效。
- 改 `project.yml` / 新增 / 移动 `.swift` 后 **必 `xcodegen generate`**。`project.yml` 已含 `schemes: AppLaunchpad:` 段，`xcodegen generate` 会生成共享 scheme `xcshareddata/xcschemes/AppLaunchpad.xcscheme`，命令行 `-scheme` 可用。

### TCC（辅助功能授权）
- 清理残留：`tccutil reset Accessibility com.biliww.applaunchpad`。
- 改 bundle id 后旧授权失效，需重授权 + ⌘Q 重启；`tccutil reset` 报 `-10814`（`errSecItemNotFound`，TCC 无此记录）= 可忽略。
- ⚠️ 本环境 sandbox 限制 `tccutil` 跑不了（报 `Operation not permitted from sandbox`，系统 tccd XPC 权限），须用户本机跑。真正授权需 App 内点「一键添加辅助功能权限」按钮触发 `AXIsProcessTrustedWithOptions(prompt:true)` + ⌘Q 重启。

### macOS 26 SDK 更名
- `recycleURLs` → `recycle`（`NSWorkspace.shared.recycle([url])`）。
- `showWindow:` 声明在 `NSWindowController` → `#selector(NSWindowController.showWindow(_:))`。

## 3. 架构要点

- **单一状态源**：`LaunchpadData`（`@Observable`）持有全部共享状态；4 个控制器 `LayoutService`(几何/布局/扫描)、`SearchController`、`DragController`(边缘翻页 Timer.common)、`NavigationController`；根 `LaunchpadViewModel` 组合根 + 薄壳转发；依赖单向 View → 根 VM → 控制器。
- **窗口**：
  - `LaunchpadWindowController` 管理 borderless `KeyablePanel`（NSPanel，`canBecomeKey/canBecomeMain = true` 重写，否则 SwiftUI `TextField` 无法聚焦）。
  - `show()` 用 `UserPreferences.shared.targetScreen` 定位到指定显示器；面板 `level = screenSaverWindow - 1`（极高，盖 Dock/菜单栏/一切）。
  - 设置窗 = 标准 SwiftUI `Window("设置", id:"settings")` + `NavigationSplitView`（通用/外观/交互/关于），**普通独立窗口，不浮于启动台之上**（"设置悬浮"已决策不做，见 `待办事项.md` C1）。
- **显示器选择**：`UserPreferences.DisplayTarget`(primary/mouse/specific(CGDirectDisplayID)) → `targetScreen` 解析 `NSScreen`；单显时仅显示"主显示器"不可选。

## 4. 数据 / 持久化

- **布局**：`LayoutStore`(actor) 读写 `~/Library/Application Support/AppLaunchpad/layout.json`。结构 `LayoutData`：`pages: [[LayoutItem]]`（`LayoutItem` 枚举 `.app`/`.folder`）+ `folders: [UUID: FolderInfo]` + `version`。`folders` 字段**运行期非空**（文件夹功能完整实现，旧文档"恒空/已移除"系误述）。
- **偏好**：`UserPreferences` → `UserDefaults.standard`，按 bundle id `com.biliww.applaunchpad` 分域。改 bundle id 后历史设置清零。
- **保存时机**：`LaunchpadData.saveLayout()`（原子写 + 清理空页）。设值后用 `UserPreferences` 的 `didSet` 触发持久化。

## 5. 编码坑全集（带正确写法）

> 每条都是真实踩过的。改相关代码前先读。

1. **Swift 6 成员初始化器不含带默认值的存储属性**；`NSEvent.Phase` 是 `OptionSet`，用 `.isEmpty` 判无惯性（翻页 monitor 区分 `phase`/`momentumPhase`）。
2. **App 中文名手写匹配**：禁用 `Bundle.localizedString` / `localizedInfoDictionary`（en 开发语言 + 无 `CFBundleLocalizations` 时错选 en，如 `wechatwebdevtools`）。见 `AppScanner.localizedDisplayName`：列 `Contents/Resources/*.lproj`，按 `Locale.preferredLanguages` 生成候选（**地区码取 `parts.last` 非 `parts[1]`**），命中读 `InfoPlist.strings` 的 `CFBundleDisplayName`。
3. **键盘 monitor 焦点门控**：`isTextInputFirstResponder()` 放行必须同时要求 `!searchText.isEmpty`（聚焦空 + 可打印字符 return event 交 IME；聚焦有内容全交还；否则字母搜索/导航）。方向键/ESC 落入导航保翻页。
4. **搜索框 `@FocusState` 上提父视图**（`LaunchpadView` 持有 `searchFocused`），`onChange(isVisible)` 中 `searchFocused = false; DispatchQueue.main.async { searchFocused = true }` 强制聚焦；否则 IME 分裂 + 焦点残留吞箭头（`NSHostingView` 复用不重建导致残留）。
5. **macOS 26 设置 Toggle 视觉**：统一 `.toggleStyle(.switch).controlSize(.large/.regular)`；行内「字段-值」用 `LabeledContent("键") { 值 }` 替代 `HStack` + `Spacer`。
6. **borderless NSPanel 无法成为 key window** → `KeyablePanel` 重写 `canBecomeKey/canBecomeMain = true`，否则 TextField 无法聚焦。
7. **`@GestureState` 跨手势重建保留拖拽起点**：`LaunchpadView` 用 `@GestureState private var dragStart`（实例属性），若用闭包局部变量，body 重算会重建手势导致 `onEnded` 跑在新实例上、`endDrag` 不执行（松手后无法点击）。
8. **`@ObservationIgnored` 网格几何避免重渲染死循环**：`LaunchpadData.gridGeometry` 标 `@ObservationIgnored`（GeometryReader 每帧写入会触发重渲染死循环）。
9. **翻页过渡起点同步**：`goToPage` 前必须同步设 `pageTransitionOffset`，否则 `onChange` 异步回调前用旧偏移渲染新页一帧 → 闪现正中。
10. **删除用 `NSWorkspace.shared.recycle([url])` 而非 `FileManager.trashItem`**：后者不写原始路径元数据，导致废纸篓"放回原处"(Put Back) 失效。
11. **Timer 必须加到 `.common` mode**：拖拽中 runloop 在事件追踪模式，default-mode Timer 不 fire，边缘翻页永不触发（`DragController.startEdgeScrollTimer`）。
12. **值类型 `@State` 手势快照陷阱**：`FolderExpandedView` 用 `class FrameBox` / `FolderGeoStore` 引用类型持有面板 frame / 首格几何，避免 `@State CGRect` 被手势闭包快照捕获为 `.zero`。
13. **`@Observable` 宏插件沙箱编译失败**：本环境必须关两层沙箱（见 §2），否则所有 `@Observable` 文件编译失败（与代码无关）。
14. **Swift 6 严格并发**：`UserPreferences` 标 `@unchecked Sendable`（含非 Sendable 的 `UserDefaults` 与枚举属性，需手动保证）；`IconCache`/`LayoutStore`/`AppScanner`/`FSEventsWatcher` 均为 `actor`；`IconCache` 用 `nonisolated(unsafe) static let cache`（NSCache 线程安全）。

## 6. 历史踩坑案例（debugging war stories）

> 改对应模块前必读，避免重演。

### 6.1 拖拽落点 clamp（两连击 bug）
- **现象**：不满页时拖完 app "两个一样的 app" / "最后一排看不见" / 翻页后 `Array out of range` 崩溃。
- **根因**：`endDrag` / `pageItemsWithDrag` 用 `min(max(to,0), itemsPerPage-1)` clamp。满页时 `=count-1` 没问题；**不满页时 `itemsPerPage-1 >> count-1`** → 插入位置偏移或越界。
- **修法**：一律 `min(max(to, 0), items.count)`（=remove 后的 count）。满页等价末格、不满页等价 append，永不越界。
- **红线**：clamp 用 `items.count` / `dstItems.count`，**绝不用 `itemsPerPage - 1`**；跨页移动必须查重去重。遇"重复"类 bug 必先 `python -m json.tool` + 全文搜 bundleID 看 `layout.json` 铁证。

### 6.2 拖完无法翻页
- **根因**：`globalDragGesture.updating` 调 `enterEditMode()`，但 `endDrag()` 只重置 `dragState`、不退出编辑 → `isEditMode` 持续 true；`pagingDragGesture` 守卫 `!viewModel.isEditMode` 把翻页整体屏蔽，需点空白 `exitEditMode` 才恢复。
- **修法**：移除翻页守卫的 `!isEditMode`。`isEditMode` 只控视觉（抖动/X），不屏蔽翻页。

### 6.3 键盘箭头被吞 + 拼音 IME 分裂
- **箭头被吞**：`isTextInputFirstResponder()` **无条件** return 所有键；`NSHostingView` 复用致搜索框焦点残留 → 左右箭头被吞。修：放行条件加 `!viewModel.searchText.isEmpty`。
- **拼音分裂**：为修箭头曾强制 `searchFocused=false` 导致搜索框永不聚焦，打拼音时首字母被 monitor 直接 `searchText+=`、后段由 IME 写回 → 分裂。修：`show()` 时 `false; async true` 强制重新聚焦 + monitor「聚焦且空」时**可打印字符 return event 交还输入框**（不自行 `+=`）。

### 6.4 App 显示名本地化（wechatwebdevtools 显英文）
- 见坑 #2。Foundation `preferredLocalizations` 对 `CFBundleDevelopmentRegion="en"` 无 `CFBundleLocalizations` 的 app 错选 en。手写匹配解决。

### 6.5 文件夹功能"移除/恢复"反复
- 曾为修 bug 误删 3 个文件夹文件 + 改 `mergeLayout` 展开 `.folder`（layout.json 12 个 `.folder` 异常格式 `list-of-pairs` 仍被容错解码保留）。后因用户反馈"无法建文件夹"从 git HEAD 恢复全部。
- **教训**：「彻底移除 X」类重构必须先删文件 + 改 `project.yml` 引用 + `xcodegen generate`，否则旧文件仍导致新逻辑分支跳不过；删 enum case 前保留 case + 默认值作兼容兜底。

### 6.6 设置窗口悬浮（已放弃，详见 BACKLOG C1）
- 5 个方案均判"不行"：降面板 hack 时序竞态 / `.background` 子视图 `makeNSView` 时 `window==nil` 设不了 level / `Window(id:)` 关闭后 `openWindow(id:)` 重开不可靠 / `.contextMenu`+`DragGesture` 冲突 / 手动托管整体被否。最终用户 20:19 回滚，设置窗口回归普通独立窗口。
