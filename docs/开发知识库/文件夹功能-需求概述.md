# 文件夹功能 — 需求概述

> 详细实现方案见 [文件夹创建功能的实现.md](./文件夹创建功能的实现.md)

## 功能清单

| 编号 | 功能 | 优先级 | 状态 |
|------|------|--------|------|
| F-01 | 拖拽 app A 到 app B 图标上 → 创建文件夹 | P0 | 🔧 开发中 |
| F-02 | 文件夹缩略图（3×3 小图标 + 名称） | P0 | ✅ 完成 |
| F-03 | 点击文件夹弹出展开视图 | P0 | ✅ 完成 |
| F-04 | 拖拽 app 到已有文件夹上 → 添加到文件夹 | P1 | ✅ 完成 |

| F-06 | 文件夹数据持久化到 layout.json | P0 | ✅ 完成 |
| F-07 | 编辑模式下文件夹可重命名 | P2 | 📋 待实施 |
| F-08 | 文件夹在网格中可拖拽重排 | P1 | 📋 待实施 |

## 核心交互设计

- **图标悬停**：光标进入目标 app 的 icon footprint → 目标保持原位、被拖 app 从网格移除仅浮动图标悬停 → 松手创建文件夹
- **缝隙让位**：光标在图标间隙 → 正常弹簧 make-way → 松手重排
- 详见 [文件夹创建功能的实现.md](./文件夹创建功能的实现.md) 的逐帧推演
