# 文件夹创建功能的实现 — 悬停图标 / 缝隙让位方案

> 日期：2026-07-24 | 核心：光标压在 app 图标上 → 关闭让位 + 目标不动；光标在缝隙 → 正常弹簧让位

---

## 一、交互规则

```
光标检测（icon footprint 精度，非 cell 精度）：
  │
  ├── 光标压在 app B 的 icon 上 → 文件夹模式
  │   ├── pageItemsWithDrag: 仅移除被拖 app（不 insert），目标 B 留在原位
  │   ├── 网格现缺口，浮动图标🎈自由悬停在 B 上方
  │   ├── B 放大 + 视觉提示
  │   └── 松手 → endDrag 在 B 的 slot 创建文件夹
  │
  ├── 光标压在 app A 自己的 icon 上 → 忽略（不触发悬停）
  │
  └── 光标在 icon 间的缝隙 → 排序模式
      ├── pageItemsWithDrag: 正常 make-way（A 占 cursorSlot，其余推开）
      └── 松手 → endDrag 执行 insert at to 重排
```

## 二、逐帧推演

### 场景：拖拽微信到抖音上创建文件夹

**初始**：第 0 页网格

```
[ micro₀ ] [ douyin₁ ] [ iqiyi₂ ]
   微信₀      抖音₁        爱奇艺₂
```

### 帧 1 — 拖拽开始，光标在缝隙

用户长按微信，开始拖拽。光标在微信图标右边缘和抖音图标左边缘之间的缝隙。

```
detectHoverTarget:
  cursorSlot = slotUnderCursor(光标) = 0
  原始布局 slot₀ 的 iconRect → 不包含光标（光标已移出微信 icon 右侧）
  原始布局 slot₁ 的 iconRect → 不包含光标（光标还没到抖音 icon 左侧）
  → hoverTargetBundleID = nil
  → hoverTargetSlot = nil

pageItemsWithDrag(page=0):
  src = 0, cursorSlot = 0
  → remove(at: 0), insert(at: 0)
  → [ micro₀ ] [ douyin₁ ] [ iqiyi₂ ]  (顺序未变，src==cursorSlot)

GridPageView 渲染：
  [ micro ] [ douyin ] [ iqiyi ]   ← 网格
  🎈 micro 浮动图标在光标处          ← zIndex 999, scale 1.12, shadow
```

### 帧 2 — 光标右移，进入抖音的 icon 范围

光标继续右移，坐标落在 `GridGeometry.iconRect(forSlot: 1)` 内（抖音图标的 64×64 区域）。

```
detectHoverTarget:
  cursorSlot = slotUnderCursor(光标) = 1
  原始布局 slot₁ = .app("douyin")
  iconRect(forSlot: 1).insetBy(-8).contains(光标) = true ✅
  bundleID("douyin") != draggedBundleID("micro") = true
  → hoverTargetBundleID = "douyin"
  → hoverTargetSlot = 1

pageItemsWithDrag(page=0):  ← hoverTarget 非空，走文件夹模式
  原始: [ micro₀ ] [ douyin₁ ] [ iqiyi₂ ]
  src = 0
  → remove(at: 0) → [ douyin₀ ] [ iqiyi₁ ]
  → **不 insert**（被拖 app 不占网格位，只在浮动图标里）
  → return [ douyin₀ ] [ iqiyi₁ ]

GridPageView 渲染：
  [ douyin🔍 1.15x ] [ iqiyi ]   ← 抖音放大，微信的网格位空缺
  🎈 微信浮动图标在光标处(抖音icon上方) ← 自由拖拽，未被"快照"到任何格子

视觉：用户看到微信浮动图标悬停在放大的抖音上方 → "要合并"
```

### 帧 3 — 光标继续右移，移出抖音 icon，进入缝隙

```
detectHoverTarget:
  originSlot₁ iconRect 不再包含光标 → hoverTagetBundleID = nil
  → 退出文件夹模式，回到排序模式

pageItemsWithDrag(page=0):
  src = 0, cursorSlot = 1 (缝隙右偏→slot1)
  → remove(at: 0), insert(at: 1)
  → [ douyin₀ ] [ micro₁ ] [ iqiyi₂ ]

GridPageView 渲染：
  [ douyin ] [ micro ] [ iqiyi ]  ← 微信用弹簧弹到光标位
  🎈 micro 浮动图标在光标处
```

### 帧 4 — 松手（光标在抖音 icon 上）

```
onEnded:
  viewModel.dragState.hoverTargetBundleID = "douyin"  ✅ 非空
  
endDrag:
  → 分支 1：创建文件夹
  draggedID = "micro", targetBundleID = "douyin"
  
  1. removeFromPage("micro", pageIndex=0)
     原: [ douyin₀ ] [ iqiyi₁ ] → [ douyin₀ ] [ iqiyi₁ ] (微已不在网格)

  2. removeFromPage("douyin", pageIndex=0)
     [ douyin₀ ] [ iqiyi₁ ] → [ iqiyi₀ ]

  3. insertSlot = hoverTargetSlot = 1
     但移除两个 app 后，insertSlot=1 越界（只剩 [ iqiyi₀ ], count=1）
     → insertSlot = min(1, 1) = 1  (insert at end)

  4. folderController.createFolder(["micro","douyin"], atPage:0, atSlot:1)
     → pages[0]: [ iqiyi₀ ] [ 📁抖音₁ ]
     → folders[UUID]: FolderInfo(appIDs: ["micro","douyin"], name:"微信")

GridPageView 渲染（松手后）：
  [ iqiyi ] [ 📁抖音 ]  ← 文件夹缩略图出现在抖音原位置附近
```

## 三、技术实现要点

### 3.1 detectHoverTarget — icon footprint 检测

```swift
private func detectHoverTarget(location: CGPoint, geo: GridGeometry) {
    guard data.currentPageIndex < data.layout.pages.count else { clearHover(); return }
    let pageItems = data.layout.pages[data.currentPageIndex] // 原始布局

    for (slotIndex, item) in pageItems.enumerated() {
        let iconRect = geo.iconRect(forSlot: slotIndex)
        let globalRect = CGRect(
            x: geo.origin.x + iconRect.origin.x,
            y: geo.origin.y + iconRect.origin.y,
            width: iconRect.width, height: iconRect.height
        )
        let hitRect = globalRect.insetBy(dx: -8, dy: -8)
        guard hitRect.contains(location) else { continue }

        switch item {
        case .app(let bundleID):
            if bundleID != data.dragState.draggedBundleID {
                data.dragState.hoverTargetBundleID = bundleID
                data.dragState.hoverTargetSlot = slotIndex  // 记录原格位
                data.dragState.hoverTargetFolderID = nil
                return
            }
        case .folder(let folderID):
            data.dragState.hoverTargetFolderID = folderID
            data.dragState.hoverTargetSlot = slotIndex
            data.dragState.hoverTargetBundleID = nil
            return
        }
    }
    clearHover()
}
```

### 3.2 pageItemsWithDrag — hover 时只移除不插入

```swift
func pageItemsWithDrag(pageIndex: Int) -> [LayoutItem] {
    guard data.dragState.isDragging,
          pageIndex < data.layout.pages.count else {
        return pageIndex < data.layout.pages.count ? data.layout.pages[pageIndex] : []
    }

    // ── 文件夹模式：被拖 app 在网格中留空，仅浮动图标悬停在目标上方 ──
    if let hoverSlot = data.dragState.hoverTargetSlot,
       pageIndex == data.dragState.sourcePageIndex {
        let src = data.dragState.sourceSlotIndex
        var items = data.layout.pages[pageIndex]
        guard src < items.count else { return items }
        items.remove(at: src)  // 移除被拖 app，不 insert → 原位置留空
        return items
    }

    // ── 排序模式：正常 make-way ──
    if pageIndex == data.dragState.sourcePageIndex {
        // ... 现有逻辑 remove+insert ...
    } else if data.currentPageIndex == pageIndex {
        // ... 现有跨页占位逻辑 ...
    } else {
        return data.layout.pages[pageIndex]
    }
}
```

### 3.3 DragState 新增字段

```swift
/// 悬停目标的原始槽位（用于 folder 创建时定位，与 cursorSlot 解耦）
var hoverTargetSlot: Int? = nil
```

### 3.4 endDrag — 用 hoverTargetSlot 定位文件夹

```swift
// 分支 1：创建文件夹
if let targetBundleID = data.dragState.hoverTargetBundleID {
    let draggedID = data.dragState.draggedBundleID
    let srcPage = data.dragState.sourcePageIndex

    // 从源页移除被拖 app（如果还在网格中）
    removeFromPage(draggedID, pageIndex: srcPage)
    // 从目标页移除目标 app
    removeFromPage(targetBundleID, pageIndex: data.currentPageIndex)

    // 插入位置：目标在原布局中的槽位（移除了 0~2 个 app 后自动对齐）
    var insertSlot = data.dragState.hoverTargetSlot ?? data.dragState.cursorSlot
    insertSlot = min(insertSlot, data.layout.pages[data.currentPageIndex].count)

    folderController.createFolder(
        containing: [draggedID, targetBundleID],
        atPage: data.currentPageIndex,
        atSlot: insertSlot
    )
    data.saveLayout()
    data.dragState = DragState()
    // ... pending refresh ...
    return
}
```

## 四、与现有排序功能的兼容性

| 场景 | hoverTarget | pageItemsWithDrag 行为 | endDrag 行为 |
|------|-------------|----------------------|-------------|
| 拖 app 到缝隙 | nil | 正常 make-way | insert at to（不变） |
| 拖 app 到另一个 app icon 上 | non-nil | 移除被拖 app，不 insert | 创建文件夹（新增） |
| 拖 app 到文件夹 icon 上 | non-nil (folder) | 同上 | 添加到文件夹（新增） |
| 拖 app 到自己 icon 上 | nil（被 skip） | 正常 make-way | insert at to（不变） |
| 翻页后拖到目标页 | nil（不在源页） | 跨页占位 | insert at to（不变） |
| 翻页后拖到目标页 app icon 上 | non-nil（需跨页 hover 检测） | ⚠️ 跨页 hover 暂不处理 | 重排 |

**注意**：翻页到目标页后，`pageItemsWithDrag` 的文件夹模式仅在 `sourcePageIndex == pageIndex` 时生效（因为移除操作只在源页有意义）。如果用户在目标页 hover 另一个 app，当前实现走重排。后续可扩展跨页文件夹创建。
