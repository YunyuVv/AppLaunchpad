## 使用建议
- **新接手开发**：只读 `开发指南.md` + `产品文档.md` + `待办事项.md`。
- **查历史决策/过程**：按上表分类翻对应文档，但结论以四份主文档 + 当前代码为准。
- **文档如有冲突**：以代码事实 > 四份主文档 > 其余历史文档。
