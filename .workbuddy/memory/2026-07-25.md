- **拖完 app 后无法翻页（需点一下空白才行）(01:26 用户反馈)**：
  **根因**：`globalDragGesture.updating` 拖拽起点调用 `enterEditMode()`，但 `endDrag()` 只重置 `dragState`、**从不退出编辑模式** → `isEditMode` 持续 true。而 `pagingDragGesture` 的 onChanged/onEnded 守卫都有 `!viewModel.isEditMode` 条件 → 编辑模式下翻页手势整体被 `return` 屏蔽。用户点一下空白触发 `Color.clear.onTapGesture → exitEditMode()`，`isEditMode` 变 false 才恢复 → 正好对应"点一下才能翻"。与之前 07-23「松手后无法点击」(`isDragging` 卡死) 是**同源但不同**的两道独立 guard。
  **修法**：移除 `pagingDragGesture` 两处守卫里的 `!viewModel.isEditMode`，让**编辑模式下也能翻页**（拖空白翻页 / 拖边缘自动翻页均可用），贴合原生 macOS 启动台（抖动/X 只是视觉态，不该阻断翻页；长按删 app 时也能翻页找其他页）。
  **红线**：「翻页/拖拽结束后的可交互性」由 `dragState.isDragging`（07-23 修）和 `isEditMode`（本次修）两道独立 guard 控制，二者不可混为一谈；`isEditMode` 只应影响视觉（抖动/X），**绝不可屏蔽翻页手势**。
  BUILD SUCCEEDED + app 重启验证（PID 69315 存活）。
