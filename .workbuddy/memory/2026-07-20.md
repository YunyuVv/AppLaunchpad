# 2026-07-20

## 分析：AppLaunchpad 功能优化点

对照核心源码梳理了可优化项，按"价值 × 成本"分为四象限（已用可视化矩阵呈现给用户）。

### 确凿的 Bug / 缺口
- **全局快捷键完全缺失**：AppDelegate/AppLaunchpadApp 无 NSEvent 全局监听，只能点菜单栏/Dock 呼出。
- **键盘导航缺失**：LaunchpadView 无任何方向键/回车/ESC 处理。
- **mouse 多显示器模式未生效**：UserPreferences 有 mouseScreen 选项，但 LaunchpadView.targetScreen、columnCount 都硬编码 NSScreen.screens.first。
- **跨页拖拽排序不支持**：endDrag 只在 sourcePageIndex 页重排，目标页不更新。
- **文件夹卸载残留**：mergeLayout 清理 pages 但未清理 folder.appIDs，卸载 App 后文件夹内留 stale bundleID。

### 性能/重构
- IconCache 仅内存 NSCache，冷启动对每个 app 调 NSWorkspace.icon(forFile:)，可做磁盘图标缓存。
- AppScanner 同步读 plist + 只扫 3 个固定目录，缺 /System/Applications/Utilities、/Library/Applications、自定义路径；可换 LSApplicationWorkspace。
- saveLayout 每次拖拽都写整 JSON，需防抖。
- FSEvents 监听 /System/Applications 几乎不变，可去掉。

### 优先级建议
立即做：全局快捷键、键盘导航、修 mouse 模式、文件夹悬停进度反馈、文件夹残留清理。
重点投入：跨页拖拽、磁盘图标缓存、扫描重构、拼音搜索。
顺手做：保存防抖、FSEvents 精简、设置窗口三条路径统一（showSettings NSWindow 已废弃，仅留面板内浮层）。
