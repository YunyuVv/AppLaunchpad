
## 落地动画丝滑化（两阶段弹簧）

- 用户反馈：落位的动态效果不够丝滑。
- 改造为**两阶段落地动画**，取代之前「浮动图标原地渐隐」的硬切效果。
- 阶段 1（滑入）：`endDrag` 提交排布后用 `isLanding=true` + `landingTarget` 驱动，`dragLocation` 经 `.interactiveSpring(0.3, 0.55)` 从光标弹入目标格子中心；同时 `isDragging=false` 让 make-way 坍塌、网格重排入位。
- 阶段 2（融入）：~260ms 后用 `easeOut(0.12)` reset `dragState`，浮动图标渐隐、格子图标同时出现。
- 变更文件：
  - `DragState.swift`：加 `isLanding: Bool` / `landingTarget: CGPoint`
  - `DragController.swift`：加 `import SwiftUI`，`endDrag` 尾部改写为两阶段动画
  - `GridPageView.swift`：`isDragged` / `isSelected` 判断扩展为 `isDragging||isLanding`，保证滑入阶段格子图标隐藏、浮动图标可见
  - `LaunchpadView.swift`：`floatingDragIcon` 显示条件加 `|| ds.isLanding`；根视图加 `.animation(easeOut, value: isLanding)`
- BUILD SUCCEEDED，app 已启动（pid 68402），待真机拖拽验证滑入丝滑度。

## 修正：弹簧阻尼过低导致"先下后上"过冲

- 阶段1弹簧 `interactiveSpring(0.3, 0.55)` 阻尼太低、过冲严重 → 图标先从光标冲过目标格子再弹回来。
- 改为 `.spring(response: 0.35, dampingFraction: 0.82)`（高阻尼，与根视图动画一致），近乎无过冲、直滑入位。
- BUILD SUCCEEDED，app 已启动（pid 71711），待验证。

## 回退两阶段落地动画 → 简洁渐隐渐显

- 用户反馈两阶段弹簧仍有 V 形轨迹（过冲导致"先下后上"），要求"只让 app 位置融入到格子中心"——即纯融合，无空间轨迹。
- 回退所有 `isLanding`/`landingTarget` 相关代码，`endDrag` 回到简单的 commit + reset。
- `onEnded` 动画改为 `.easeOut(0.28)`：浮动图标渐隐 + 格子图标出现 + GridPageView spring(0.45, 0.8) 重排入位，三线各自独立无轨迹。
- 变更：
  - `DragState.swift`：删 `isLanding`/`landingTarget`，`isEmpty` 恢复 `!isDragging`
  - `DragController.swift`：删 `import SwiftUI`，`endDrag` 尾部回到 `data.dragState = DragState()`
  - `LaunchpadView.swift`：删 `.animation(value: isLanding)`，`floatingDragIcon` 条件恢复 `isDragging`，`onEnded` 动画改 `easeOut(duration: 0.28)`
  - `GridPageView.swift`：`isDragged`/`isSelected` 恢复仅 `isDragging` 判断
- BUILD SUCCEEDED，app 已启动（pid 71972）。

## 修复：翻页后目标页无让位效果

- 根因：`pageItemsWithDrag` 的 guard 条件 `sourcePageIndex == pageIndex` 导致让位仅在源页生效，翻页后目标页拿原始布局、无缺口。
- 修复：
  - guard 移除 `sourcePageIndex == pageIndex` 限制
  - 三板斧：`sourcePageIndex == pageIndex` → 源页 make-way（remove+insert）；`currentPageIndex == pageIndex` → 目标页占位插入（`.app(bundleID:)` 插入 cursorSlot）；其余 → 原始布局
- `endDrag` 落点逻辑不变（已正确处理跨页重排）。
- BUILD SUCCEEDED，app 已启动（pid 73334）。
