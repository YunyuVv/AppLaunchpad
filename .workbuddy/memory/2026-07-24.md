## 文件夹面板拖出 → 接管主网格拖拽（不松手）

**用户需求**：把 app 拖出文件夹面板后，手不会松开（要在主网格继续调顺序），所以面板必须在 app 离开范围时立刻关闭并接管到主网格拖拽，而不是等松手。

**两个根因**：
1. `FolderExpandedView` 之前用 `.allowsHitTesting(!isDraggingOut)`——拖出后整个面板 hitTesting 关掉 → 手势宿主（AppIconView）失去命中 → 手势立即结束，所以只能等松手回调。
2. `FolderController.removeApp` 只把 app 从文件夹移除，**没有插回主网格 `pages`**——即便接上主网格，`DragController.beginDrag` 也找不到这个 app（`firstIndex` guard 失败）。

**修复方案**：
1. `FolderController.removeAppAndReinsert(bundleID, fromFolder:)` → 先定位 `.folder(folderID)` 在 pages 中的位置 → `removeApp`（可能删除空文件夹）→ 把 app 插回该页该槽位 → 返回 page。
2. `FolderExpandedView`：`onDragOut` 拆成三个回调：
   - `onDragOutHandoff(app, location)`：第一次超出 panel 时调用（一次性）
   - `onDragOutMove(location)`：交接后持续把光标位置喂给主网格
   - `onDragOutEnd()`：松手时主网格 endDrag + 关闭面板
3. 去掉 `.allowsHitTesting(!isDraggingOut)`，仅靠 `.opacity(isDraggingOut ? 0 : 1)` 隐藏面板——**opacity 不影响 hitTesting**，手势宿主保留在层级中，手势继续运行直到真正松手。
4. `LaunchpadView` 接线新回调：
   - handoff：`removeAppAndReinsert + saveLayout + enterEditMode + beginDrag(pageIndex: reinsertPage, location:)`
   - move：`viewModel.updateDragTarget(location:)`
   - end：`viewModel.endDrag() + expandedFolderID = nil`

**变更文件**：
- `FolderController.swift`：新增 `removeAppAndReinsert`（@discardableResult，返回 Int）
- `FolderExpandedView.swift`：拆 `onDragOut` 为三回调 + 重写 `dragGesture(for:)` 的 onChanged/onEnded + body 去掉 `allowsHitTesting`
- `LaunchpadView.swift`：FolderExpandedView 实例化处改用新回调

## @State 值类型快照捕获 bug 修复（核心漏洞）

**现象**：拖出面板检测永不触发——`panelFrame` 在手势闭包里永远是 `.zero`。

**根因**：`@State var panelFrame: CGRect` 是值类型。手势闭包创建时捕获 `self.panelFrame` 快照（此时为 `.zero`）。之后 `onPreferenceChange` 更新了 panelFrame，但 SwiftUI 不会重建已激活的手势闭包 → 闭包内仍是 `.zero`。

**修复**：用 `class FrameBox { var frame: CGRect = .zero }` 包裹。`@State` 对 class 存的是引用；修改 `frame` 不改变引用 → 手势闭包通过指针始终读到最新值。

同时改用 `onAppear` 主动计算 frame（不等 PreferenceKey）：
```swift
.onAppear {
    let globalOrigin = geo.frame(in: .global).origin
    panelFrameBox.frame = CGRect(
        x: globalOrigin.x + (geo.size.width - panelW) / 2,
        y: globalOrigin.y + (geo.size.height - panelH) / 2,
        width: panelW, height: panelH
    )
}
```

- 删除了 `PanelFrameKey` PreferenceKey 定义和相关 `.background(GeometryReader{...})` / `.onPreferenceChange`
